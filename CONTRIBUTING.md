# Contributing

Keep changes focused, document observable behavior, and run the checks in
[Testing](TESTING.md). Preserve wire formats, saved-data contracts, and scientific
semantics unless the change explicitly updates them.

This repository is intended for public distribution. Include only shareable
source, documentation, licensed dependencies, and synthetic or permitted fixtures.
Keep model weights, private datasets, credentials, research notes, and internal
presentations out of commits.

When bringing work from a private repository, apply and review the selected file
changes. Do not merge its branches or copy its Git history. Review new files,
licenses, bundled packages, and the full staged diff before pushing.
